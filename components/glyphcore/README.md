# GlyphCore в общем проекте

Закреплённая версия: **0.1.29**. Компонент отвечает за отрисовку отсутствующих
глифов. Используется официальный `version.dll`, его SHA256 записан в
`components.lock.json`. Шрифт и базовые настройки принадлежат общей сборке:
`assets/fonts/` и `profiles/default.json`.

Официальный репозиторий: https://github.com/nourlie/GlyphCore
Бинарный файл: https://github.com/nourlie/GlyphCore/releases/tag/v0.1.29

Публичный репозиторий содержит MIT-лицензию и `gw2-dat-tool`. Исходники
`version-proxy` вынесены в приватный Git-подмодуль `GlyphCore-Private`:
https://github.com/nourlie/GlyphCore/blob/v0.1.29/.gitmodules
Поэтому воспроизводимая сборка самой DLL из доступных здесь исходников
невозможна. Она подключена как внешняя зависимость с фиксированной версией.

В `dat-tool/` сохранён открытый инструмент чтения архива с локальными изменениями,
ранее подготовленными для извлечения доступного текста. Исходные варианты
изменённых файлов находятся в `upstream-original/`.

Профиль выключает перевод, отправку собранных строк и автообновление GlyphCore.
Локальный сбор соответствий ID включён. Текст подставляет Text Translator,
а ручные переводы и машинный кэш обслуживает русский Local Translator.
