# Русский модуль

`ru_launcher.py` — адаптер русского языка и служебные команды установки
ручного каталога, предварительного перевода и переноса кэша.
`source/src/` — исходный движок NikeGipple v0.10.0, коммит
`cfed4621c79322dec68a9cc0b7848a41060e4c07`, MIT (`source/LICENSE`).

Локальная правка в `lt_server.py`: SentencePiece получает `model_proto` из
Python `Path.read_bytes()`. Его файловый загрузчик на Windows не открыл модель
по пути с кириллицей при проверке пакета. Загрузка байтов устраняет зависимость
от кодировки пути; протокол и алгоритм перевода сохраняются.

Общая сборка использует версию адаптера `0.10.0-ru-local3`. Протокол Nexus
остаётся прежним. Готовый модуль работает без отдельной установки Python.
`reviewed_setup.py` использует общий `tools/catalog.py`; проверки и применение
ручных строк не дублируются отдельным алгоритмом в установщике.

Редакторский словарь `glossary/ru.json` в корне проекта служит для согласования
терминов. `glossary_ru.default.json` здесь — технический словарь машинного движка.
Это разные форматы и назначения; их нельзя механически подменять друг другом.
