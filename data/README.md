# Исходный импорт

`imported/` содержит сохранённые без редактирования файлы: весь рабочий
машинный кэш, весь корпус английских оригиналов, настройки его словаря,
исторический прогресс и соответствия ID. Это материал для перевода;
у данных нет статуса ручной редакции. Исходные тексты принадлежат ArenaNet.

`manifest.json` хранит SHA256 файлов. Проверка обнаружит их изменение.
Редактируемая копия находится в `drafts/ru/`; ручные принятые строки —
в `translations/ru/`. Кэш и корпус целиком включены и в репозиторий, и в пакет.

Исторический `precache-progress.json` описывает приостановленный процесс
до импорта. Наличие `phase: translating` в нём не означает работающую задачу.
Перевод остатка моделью сейчас не запускался.
