# Как участвовать

Исправления присылаются pull request'ами в репозиторий проекта на GitHub.
Для правки одной строки можно использовать редактор GitHub; локальная сборка
игры или переводчика не нужна. Веб-редактор позволит создать ветку и pull request.

## Участие через игру

Запустите `Contribute.cmd` и включите локальный сбор. Просмотрите новые строки,
при необходимости предложите перевод/контекст и отправьте выбранное через PR.
Подробная инструкция — [docs/WORKSHOP.md](docs/WORKSHOP.md).
Пакеты находятся в `contributions/ru`; проверка — `python tools/contributions.py check`.
Они остаются драфтами до редакторской проверки и переноса в основной каталог.

## Что редактировать

Без ручного редактирования JSON можно работать в мастерской: `Contribute.cmd`
из папки проекта → **Черновики** или **Переводы**. Сохранённые изменения видны
в **Мои изменения**, откуда отправляются одним PR. Папки и файлы создаются
в дереве переводов; «Добавить в переводы» формирует запись со статусом draft.
Подробности и ограничения — [инструкция мастерской](docs/WORKSHOP.md).

Общие договорённости о терминах редактируются во вкладке **Словарь**.
Файл `glossary/ru.json` можно отправить вместе с переводами через **Мои изменения**;
проверка — `python tools/glossary.py check`. Этот редакторский словарь пока не
подключён к автоматическому переводу.

Весь сохранённый массив уже включён в проект. Для постепенной редактуры
машинного перевода и заполнения пустых строк используйте `drafts/ru/`:
[инструкция](drafts/README.md). Поле `ru` можно править через редактор GitHub.
Исходный импорт в `data/imported/` остаётся без изменений. Для принятой ручной
редакции по ID используется основной каталог, описанный ниже.

Файлы находятся в `translations/ru/`. Одна запись — один игровой ID:

```json
{
  "id": 567188,
  "en": "Corruption Training",
  "ru": "Обучение порче",
  "context": "Герой → Обучение → некромант: группа умений порчи",
  "src_hash": "хеш оригинала; берётся из сбора, не придумывается",
  "status": "draft",
  "evidence": "Название и расположение проверены в игровом интерфейсе"
}
```

Пример выше иллюстрирует поля; значение `src_hash` в нём нужно заменить настоящим.
Для исправления существующего перевода достаточно менять `ru` и, при необходимости,
контекст и заметки. Новые предложения помечайте `draft`. После редакторской
проверки сопровождающий меняет статус на `reviewed`; только эти записи идут в игру.
Одного автоматического прохождения проверки недостаточно для принятия перевода.

Не меняйте оригинал или ID ради исправления русского текста. Если игра обновила
оригинал, приложите новые данные сбора: хеш связывает перевод с конкретным текстом.
Одинаковые английские слова могут требовать разного перевода в разных местах.
Не объединяйте записи с разными ID только из-за одинакового оригинала.

Сохраняйте `%str1%`, `%num1%`, `[lbracket]`, `[rbracket]`, теги цвета и другие
служебные элементы. Не подставляйте вместо них имя персонажа, число или название
предмета со своего экрана. Проверка обнаруживает потерянные и добавленные токены,
изменение порядка тегов, повторяющиеся ID и изменившийся оригинал.

## Как добавить новые строки

Игровой ID строки отличается от ID умения или предмета в GW2 API. Не угадывайте
его по соседним номерам. Для уже настроенного русского модуля доступен показ ID:
при закрытой игре запустите `Local_Translator_RU.exe --lang ru --show-keys text
--no-update --editor-port 0` из папки модуля. Затем войдите в игру и запишите ID
рядом с нужной строкой вместе с её контекстом. После сбора закройте игру и
выключите подписи командой с `--show-keys off` вместо `text`.

Чтобы подготовить JSON только выбранных ID из локального сбора:

```text
python tools/propose.py --game "G:\Guild Wars 2\Guild Wars 2" --ids 567188 --section hero/training --context "Герой → Обучение → некромант: направление порчи" --out proposal.json
```

Команда читает оригиналы из карты переводчика или seed-сбора GlyphCore, проверяет
доступные хеши и создаёт черновики с пустым русским текстом. В примере используется
уже имеющийся ID, поэтому его правку нужно вносить в существующую запись, а не
добавлять второй раз. Для новых ID заполните русский текст и перенесите записи
в нужный раздел каталога. Контекст указывает автор предложения; инструмент сам
не узнаёт окно или говорящего. Импортированный полный сбор уже сохранён отдельно
в `data/imported/`; для дальнейшей редактуры используйте черновики или основной каталог.

## Как писать

- Короткие действия: «Изучить», «Сохранить», «Просмотреть».
- Термины сверяйте с `glossary/ru.json`; неоднозначность обсуждайте в pull request.
- Сначала сохраняйте игровой смысл. Не исправляйте механику по догадке.
- Названия пользовательских билдов не являются текстом локализации.
- В описании PR указывайте раздел, причину правки и пример на экране.
  Перед добавлением скриншота уберите персональные данные и чужой чат.

## Локальная проверка

Нужен Python 3.12 или новее:

```text
python -m pip install -r requirements.txt
python tools/catalog.py check
python tools/drafts.py check
python -m unittest discover -s tests -v
python tools/catalog.py build
```

При публикации GitHub Actions выполняет те же проверки на push и pull request.
Для основной ветки следует включить обязательный review и успешный CI.
Этот репозиторий сам не меняет настройки доступа GitHub и не публикует релизы.

## Проверка в игре

Для полной установки с GlyphCore, шрифтом и моделью используйте общий
`Install.cmd` из готового пакета (инструкция в `docs/INSTALL-RU.txt`). Команды
ниже обновляют только ручной каталог в уже настроенной игре.

Работает с уже установленным русским модулем GW2 Nexus Local Translator:

```text
python tools/catalog.py install --game "G:\Guild Wars 2\Guild Wars 2"
```

Закройте игру перед установкой. Для проверки без выхода из игры остановите
русский модуль кнопкой Stop Module в Nexus, затем используйте:

```text
python tools/catalog.py install --game "G:\Guild Wars 2\Guild Wars 2" --module-stopped
```

Nexus можно открыть его кнопкой в верхнем ряду значков игры. Затем выберите
Installed → Text Translator → Configure → Options → Modules.

После этого снова запустите модуль в Nexus. Установщик отказывается работать,
пока процесс русского модуля запущен, сохраняет резервную копию, проверяет хеши
по текущему кэшу и обновляет только принятые записи. Остальные записи сохраняются.
Кэш игры не переписывается напрямую: модуль применяет исправления штатным путём.

`dist/reviewed-ru.json` — экспорт данных, а не файл для ручного копирования в RU:
часть upstream-импортёров теряет хеши оригинала. Используйте наш `install`.

## Публикация и лицензия

Наш код распространяется по MIT (`LICENSE`); сторонние компоненты сохраняют
свои условия, перечисленные в `THIRD-PARTY.md`. Перед публичным запуском
нужно выбрать владельца репозитория и лицензию на коллективные переводы. Лицензия
MIT на инструменты не предоставляет прав на исходные игровые тексты ArenaNet.
Импортированный корпус текстов и машинный кэш включены в проект по решению
владельца как материал для совместной редактуры. Архив Gw2.dat, модель,
настройки учётной записи и логи в Git не добавляются. Модель входит в готовый
установочный пакет.
