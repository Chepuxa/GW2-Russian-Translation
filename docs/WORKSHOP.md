# Мастерская перевода

## Каталог и редактор (0.5.0-local)

Запускайте `Contribute.cmd` **из той папки проекта, которую хотите редактировать**.
Вверху панели показан полный путь. Для редактирования игра не требуется.

- **Черновики** — весь `drafts/ru`, пакеты `contributions/ru` и личные находки.
  Поиск по оригиналу, переводу, контексту и ID; фильтры без перевода, с переводом,
  с ошибками форматирования и ещё не добавленные в переводы. По 30 строк на странице.
- **Переводы** — дерево `translations/ru`, создание вложенных папок и JSON,
  просмотр и исправление записей. Пустая папка сохраняется через `.gitkeep`.
- **Словарь** (с 0.6.0-local) — общий редакторский `glossary/ru.json`: поиск
  по английскому термину, русскому варианту и пояснению, добавление,
  исправление и удаление терминов. Последнее удаление можно отменить
  кнопкой «Вернуть удалённый термин» в текущей вкладке.
- **Мои изменения** — сохранённые файлы, разница до/после, выбор файлов,
  выгрузка снимка и PR с несколькими файлами.
- **Локальный сбор** — личная очередь и отправка новых оригиналов пакетом
  `contributions/ru/<batch>.json`.

Откройте **Черновики → Редактировать**, заполните русский текст и контекст,
сохраните. Через **Добавить в переводы** выберите игровой ID и JSON-файл.
Если файла нет, панель создаст его. Оригинал и черновик сохраняются; список
покажет ссылку на запись в translations. Если ID неизвестен, перевод можно
сохранить в черновиках; для переноса нужен настоящий ID из игры.
Если ID уже есть в translations, исправьте существующую запись.

Пакеты contributions сохраняют неизменную историю: свой перевод из такого
пакета вводите через «Добавить в переводы». Новые и изменённые записи каталога
получают **draft**, в том числе правки ранее проверенных переводов.
`reviewed` присваивает редактор после проверки; кнопки одобрения в панели нет.
В игру устанавливаются только reviewed; сохранение в панели не меняет игру.

Правки сохраняются в локальных файлах выбранного проекта. Устаревшая открытая
строка или внешняя правка блокируют перезапись: обновите список и повторите.
Исходные версии файлов и индекс поиска хранятся в личном `catalog-<project>.db`
рядом с inbox.db и не входят в распространяемый пакет.

Для PR откройте **Мои изменения**, выберите файлы, просмотрите разницу и
подтвердите публикацию. Отправляется точный снимок выбранных файлов.
Версии исходных файлов сверяются с GitHub: если файл там изменился, обновите
локальный проект и перенесите правки. Ветка — `community/edit-ru-<batch>`;
повторная отправка того же снимка возвращает существующий PR.
Локальные правки остаются после отправки; PR объединяет сопровождающий проекта.

Скачанный JSON изменений — резервный снимок с путями, исходными контрольными
суммами и новым содержимым файлов. Это не game-contribution: не кладите его в
contributions/ru. Для участия используйте PR либо передайте изменённые файлы
проекта сопровождающему. Автоматическое одобрение сюда не входит.

### Словарь терминов

Во вкладке **Словарь** можно исправить английское написание, русский вариант
и пояснение к значению. Контекст необязателен, но помогает отличать разные
значения одного слова. Одинаковый английский термин с одинаковым контекстом
повторно не добавляется (регистр и пробелы по краям не учитываются).
Пустые термины/переводы и управляющие символы отклоняются.

Правки сохраняются локально в `glossary/ru.json`, видны в **Моих изменениях**
и отправляются через тот же PR вместе с выбранными файлами переводов.
Для проверки используется `python tools/glossary.py check`; эта проверка
включена в сборку и GitHub CI.

Это словарь договорённостей для участников перевода. Машинный переводчик
пока использует отдельный технический словарь `glossary_ru.default.json` / RU/glossary_ru.json.
Изменения во вкладке не меняют машинный перевод, существующие черновики
или кэш игры автоматически.

## Сбор новых строк

1. Установите сборку 0.5.0-local или новее с закрытой игрой через Install.cmd.
2. Запустите Contribute.cmd, при необходимости указав путь к игре:
   `Contribute.cmd -GamePath "G:\Guild Wars 2\Guild Wars 2"`.
3. В браузере включите локальный сбор и играйте с переводчиком. Сбор можно
   выключить в любой момент; уже сохранённая очередь останется на диске.
4. В разделе «Локальный сбор» нажмите «Обновить список». Известные каталогу пары ID/оригинал пропускаются.
   Новые тексты, новые ID известных текстов и изменённые оригиналы сохраняются
   отдельно. Модель не обязана успешно ответить, чтобы оригинал сохранился.
5. При желании исправьте перевод и укажите контекст. Сначала сохраните правку,
   затем выберите строки и нажмите «Просмотреть выбранное».
6. Скачайте JSON или отправьте PR после просмотра состава пакета.

## GitHub

Укажите адрес репозитория проекта
`owner/GW2-Russian-Translation` в панели и нажмите «Сохранить».
Не указывайте исходный репозиторий движка: пакеты предназначены для нашего
проекта, в котором есть `contributions/ru` и проверка contributions.py.

GitHub CLI включён в Windows-пакет. Нажмите «Войти в GitHub», завершите вход
в отдельном окне CLI/браузере, затем нажмите «Проверить вход». Авторизацией
управляет официальный CLI; мастерская не запрашивает и не сохраняет токен.
GitHub CLI может использовать системное хранилище учётных данных, а при его
недоступности — собственный конфигурационный файл. Не включайте его в архивы.

Кнопка «Отправить PR» создаёт fork от вашего аккаунта, отдельную ветку
`community/ru-<batch>` и PR с одним файлом. Если репозиторий принадлежит вам,
ветка создаётся в нём. Повторная отправка того же содержимого проверяет
существующую ветку и возвращает прежний PR, включая уже закрытый.
Чужая существующая ветка не перезаписывается. Git и клонирование всего
репозитория игроку не требуются. Ошибка сети сохраняет очередь и подготовленный
пакет; повторите отправку. Удалённый PR не объединяется автоматически.

Без GitHub используйте «Скачать JSON». Сопровождающий проекта сможет добавить
файл в contributions/ru, выполнить проверку и принять его обычным PR.

## Что хранится локально

`addons/text_translator/modules/local_translator_ru/RU/contributions/inbox.db`
содержит очередь, настройки сбора, предложенные правки и сведения об отправке.
Она переживает перезапуски и переустановку пакета. По умолчанию сбор выключен.
Он работает только при запущенном обновлённом модуле переводчика, когда тот
получает английские оригиналы. Строки, оставшиеся только в игровом кэше и не
переданные модулю, заново не просматриваются. Полное покрытие не гарантируется.
Для переноса личной очереди закройте игру и панель и скопируйте весь каталог
RU/contributions. Обычный Export-Cache.cmd переносит переводческий кэш,
а не персональные предложения.

Протокол не сообщает тип окна, автора сообщения или задание. Поэтому
автоматически гарантировать отсутствие имён и личного текста невозможно:
проверьте выбранные строки и контекст перед публикацией. Подозрительные адреса,
имена аккаунтов и несколько оригиналов на одном ID отмечаются предупреждением.
Уберите сообщения чата, имена игроков и гильдий. Сомнительные записи можно
скрыть. Это не универсальный фильтр личных данных.

Поле game_build в первой версии остаётся пустым: достоверный номер сборки
игры текущий протокол не передаёт. Версия общего каталога записывается отдельно.
Машинный перевод помечен machine, правка участника — human; оба остаются draft.
Повреждённые теги/подстановки блокируют отправку: исправьте или очистите ru.

Панель доступна только на 127.0.0.1 со случайным ключом доступа. Кнопка
«Закрыть панель» завершает её локальный процесс; игровой сбор продолжает
работать независимо от вкладки браузера. Очередь не отправляется автоматически.
