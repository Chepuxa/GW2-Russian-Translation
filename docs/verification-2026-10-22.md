# Проверка редакции 22 октября 2026

В установленный русский модуль добавлены 232 ручные строки: первые 99 и ещё
133 для интерфейса билдов, обучения и терминов некроманта. Модуль перезапущен
через Nexus без выхода из Guild Wars 2.

Лог подтвердил `patch v2: 232 reviewed` и 232 хеша английских оригиналов.
При запуске модуль передал игре 128 отличающихся переводов: 41 исправление
существовавшего текста и 87 новых записей. Это число отличается от 133 новых
строк каталога: часть текстов уже совпадала с текущим кэшем.

Шрифт Alegreya Sans Medium, размер 90%, базовая линия 80%. Это ранее выбранные

Команды изменения билда и покупки обучения при проверке не выполнялись.

## Что ещё предстоит проверить

Не все 232 ID отдельно показаны на экране. Для нескольких игровых ID с одинаковым
оригиналом проверено отображение соответствующего названия, а не каждое место
его использования. Предупреждения, закрытые уровнем сообщения и другие профессии
требуют отдельных сценариев. Полная редактура описаний умений и черт ещё впереди.

В JSON поле `verification` хранит подробности проверки. `reviewed` означает
редакторскую готовность текста, а не автоматическое подтверждение всех экранов.
Остальная часть игры продолжает пользоваться существующим машинным переводом.

## Техническая проверка

Проверка каталога и девять локальных тестов прошли. Тесты покрывают сохранение
подстановок и порядка тегов, повторяющиеся ID и JSON-поля, хеш оригинала,
исключение черновиков, воспроизводимую сборку и сохранение посторонних записей
в базе ручных исправлений. GitHub Actions подготовлен; удалённых запусков пока нет.

Установщик сохранил резервную копию баз перед применением. Исходники перевода
не содержат модель, полный машинный кэш или логи игры. Снимки этой локальной
проверки сохранены отдельно в `.translator-setup/build-review/` рядом с игрой.
