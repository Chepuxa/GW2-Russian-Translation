# Полный кэш и корпус в общем проекте

Пакет `0.3.0-local` теперь содержит весь сохранённый машинный кэш и корпус
оригиналов. Они также включены в исходники проекта для совместной редактуры.
Новые переводы моделью при подготовке не запускались.

| Материал | Количество |
| --- | ---: |
| Оригиналы в исходном CSV | 134 253 |
| Сохранённые машинные переводы | 115 159 |
| Уникальные тексты после объединения | 146 693 |
| Черновики с пустым `ru` | 31 534 |
| Ручные reviewed-записи | 232 |
| ID в начальной машинной базе | 156 367 |

Число игровых ID больше числа переводов: один английский текст может
использоваться несколькими ID. Известные ID ручной редакции в начальную
машинную базу не включены.
Четыре искусственных ID из прежнего теста протокола не помечаются как игровые;
исходный импорт, включая эти записи, сохранён без изменений.

`data/imported/` хранит исходные файлы без изменений с SHA256. В `drafts/ru/`
созданы 256 редактируемых JSON. Все 146 693 записи имеют статус `draft`.
ID указаны там, где удалось сопоставить оригинал; поле контекста пока пустое.
Машинные ошибки не исправлялись автоматически. Проверка нашла 21 509
заполненных черновиков, у которых нужно проверить подстановки, теги или
служебные символы; перед принятием ручной строки такие ошибки нужно исправить.

Готовый ZIP включает исходники, весь импорт, черновики и `bootstrap-cache.zip`.
Установщик автоматически сливает начальный кэш с существующим, затем
устанавливает ручной каталог. Уже накопленные записи и ручные исправления
сохраняются. При несовместимом пользовательском словаре кэш пропускается
с сообщением; он всё равно остаётся в составе пакета.

## Проверка

- Проверка всего импорта и 146 693 черновиков прошла.
- 23 модульных теста прошли, включая сохранение исходного машинного текста,
  применение правок в следующей сборке, предложение ручной строки с контекстом
  и исключение reviewed-ID из машинной базы.
- Реальный установщик PowerShell 5.1 применил все 115 159 переводов и начальную
  базу в изолированной папке с кириллицей в пути.
- Проверены повторная установка, сохранение пользовательских записей и настроек,
  перенос и повторный импорт кэша, сохранение дополнительных ручных строк,
  конфликт загрузчика и отказ при нарушении SHA256 пакета.
- Реальный упакованный EXE проверен по протоколу Nexus с отключённой моделью
  (`--fake`). Ответы получены из готового кэша, словаря и ручного слоя:
  «Поговорите с разведчиком.», «Инвентарь», «Обучение порче».
  Служебные подстановки и теги сохранены. У проверенных ответов не было
  обращения к модели перевода.

Локальные отчёты установки находятся в `.artifacts/install-smoke-*/`. Сборка не обновляет
работающую игровую сессию: установщик нового пакета запускается при закрытой игре.
GitHub ещё не опубликован, но весь материал включён в исходники для отправки PR.
