# Проверка общего пакета — 22 октября 2026

Версия пакета `0.2.0-local`, русский модуль `0.10.0-ru-local3`.
В одном архиве 171 файл payload: Nexus, Text Translator, GlyphCore,
Alegreya Sans Medium, русский EXE с runtime и моделью, общий профиль
и 232 ручных перевода. Личный машинный кэш не включён.

## Проверенные сценарии

Установщик запущен под Windows PowerShell 5.1 в изолированных папках
с фиктивными `Gw2-64.exe` и `Gw2.dat`. Эти фиктивные файлы не запускались
и не сканировались. Настоящая запущенная игра во время проверки не менялась.

- Чистая установка глифов, шрифта, модели и всех 232 reviewed-строк.
- Путь с кириллицей, пробелами и символом `$`.
- Повторная установка сохраняет машинный кэш, посторонние ручные записи,
  пользовательскую настройку обновления текста и другое дополнение.
- Общий профиль применяет размер 90%, базовую линию 80%, выключает
  дублирующий перевод и отправку строк GlyphCore.
- Включение и отключение перевода сохраняют кэш.
- Экспорт и импорт машинного кэша и дополнительных ручных исправлений.
- Повторный импорт не добавляет повторяющиеся записи.
- Конфликт существующего загрузчика останавливает установку, сохраняя файл.
- Изменение файла пакета обнаруживается до копирования файлов в игру.

Отдельно запущен установленный EXE с реальным бинарным протоколом Nexus,
моделью и токенизаторами. Подтверждены протокол 2, ключ кэша `ru`, ручной
ответ «Обучение порче», машинный ответ «Поговорите с разведчиком.» и сохранение
`%num1%`, `<br>`, цветовых тегов и названия Guild Wars 2.

При первой проверке выявлена ошибка SentencePiece: файловый загрузчик
не открывал модель в пути с кириллицей. В общем проекте токенизаторы
загружаются через байты Python; повторная проверка упакованного EXE прошла.

Проверка каталога, 15 модульных тестов, компиляция Python-источников
и проверка SHA256 закреплённого runtime прошли. GitHub Actions подготовлен
для Windows и Linux, но удалённый запуск ещё не выполнялся.

## Границы проверки

Новая версия EXE проверена в изолированной установке и по реальному протоколу,
но ещё не заменяет модуль работающей игровой сессии. В ней продолжают работать
ранее установленные 232 ручные строки. Проверка их отображения описана в
[отчёте окна героя](verification-2026-10-22.md). DLL GlyphCore, Nexus,
Text Translator и файл шрифта в общем пакете совпадают с уже проверенными
в этой игровой установке файлами.

Локальные технические отчёты находятся в `.artifacts/install-smoke-056d7802/`.
Предыдущий комплект сохранён в `.translator-setup/legacy/GW2-Russian-Translator/`
рядом с игрой. Актуальный код и инструкция теперь находятся в одном проекте.
