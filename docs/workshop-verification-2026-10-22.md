  Сбой сети оставил локальную очередь и подготовленный пакет для повтора.
- Нативный установщик Windows PowerShell 5.1 проверен: чистая установка,
  повторная установка с сохранением личной очереди, кэша и ручных записей,

## Границы проверки

Реальный PR на GitHub **не создавался**: пользовательский репозиторий ещё
не опубликован, адрес в панели пустой. Авторизация официального CLI и права
конкретного аккаунта потребуют проверки после появления репозитория.
GitHub Actions подготовлен, но удалённо ещё не запускался.

Игра после этой установки не запускалась; сбор проверен нативным протоколом
в изолированной установке. Контекст окна/диалога и номер игровой сборки
текущий протокол не передаёт. Отсутствие личных данных должен дополнительно
проверять участник перед публикацией. Сбор не гарантирует получение всех
строк, особенно тех, которые модуль уже не получает из игрового кэша.

Машинные и пользовательские предложения остаются драфтами. Сбор/редактура
очереди не применяют эти предложения в игре и не меняют reviewed-каталог.
