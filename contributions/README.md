# Предложения из игры

`ru/<batch>.json` — небольшие пакеты новых строк и предложенного перевода.
Их создаёт «Мастерская перевода», открываемая через `Contribute.cmd`.
Это дополнительный слой драфтов; принятие PR не выдаёт статус `reviewed`
и не заменяет ручной каталог `translations/ru`.

Пакет содержит только выбранные оригиналы, ID, хеши, русский драфт,
происхождение перевода и необязательный контекст. Логи, локальные пути,
имена аккаунтов GitHub, даты наблюдения и личная база в пакет не входят.
Автор PR виден средствами GitHub. Снимки экрана автоматически не собираются.

Проверка перед принятием: `python tools/contributions.py check`.
Она проверяет структуру, статус draft, хеш оригинала, теги, подстановки
и контрольную сумму содержимого. Редактору нужно дополнительно проверить,
что строки относятся к игре и не содержат личных данных. Поле `context`
является пометкой участника, а не автоматически доказанным контекстом.

Пакеты неизменяемы: правка содержимого требует нового имени batch,
равного первым 24 знакам SHA256 канонического JSON без поля batch.
Разные участники могут предложить одну строку с разным переводом:
это допустимые альтернативы для редакторского выбора. Внутри одного пакета
повтор пары `(id,src_hash)` запрещён. Изменение оригинала создаёт отдельную
редакцию; прежний текст и проверенный перевод сохраняются.

После принятия пакета его ID и оригиналы включаются в индекс известных
строк следующей сборки. Русские предложения остаются в этом слое до
ручного переноса в основной каталог по правилам CONTRIBUTING.md.
