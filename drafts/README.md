# Весь корпус и машинный кэш для совместной редактуры

Здесь **146 693 уникальных английских текста**: объединение 134 253 оригиналов
корпуса и 115 159 строк сохранённого машинного кэша. Они частично пересекаются.
У 115 159 записей есть исходный машинный перевод, у 31 534 поле `ru` пустое.
Новые переводы моделью при импорте не запускались.

`ru/p-00.json` … `ru/p-ff.json` — 256 небольших файлов. Найдите английский
текст и исправьте `ru`; для непереведённого текста заполните его. Добавьте
контекст, если знаете окно, предмет или говорящего. Все записи первоначально
имеют `status: draft`; перевод может быть ошибочным.

```text
rg -n "нужный английский текст" drafts/ru
python tools/drafts.py check
```

`key` — XXH3-64 оригинала, `ids` — известные игровые ID с точно таким текстом.
ID отсутствуют у части строк и могут быть множественными. Пустой `context`
означает, что контекст ещё не установлен. Его нельзя достоверно восстановить
из одного английского текста. Не меняйте оригинал, ключ или ID ради правки `ru`.

Машинные строки сохранены как есть, в том числе с ошибками служебных элементов.
Проверка сообщает их количество; перед принятием ручной строки нужно восстановить
теги и подстановки. `draft` не означает, что машинный текст проверен.

Для выбранного известного ID можно подготовить предложение в основной каталог:

```text
python tools/drafts.py propose --key КЛЮЧ --id ИГРОВОЙ_ID --context "Герой → окно или подсказка" --out proposal.json
```

После проверки перенесите предложение в `translations/ru/` и пройдите обычное
редакторское принятие. Если ID уже есть в основном каталоге, правьте существующую
запись. Ручные `reviewed`-строки имеют приоритет над этим машинным слоем.

Сборщик включает заполненные черновики в начальный машинный кэш для игры.
Обновление сохраняет уже накопленные записи пользователя. Чтобы принятая правка
заменила старый перевод в существующей установке, добавьте её как ручной перевод
по игровому ID: простая правка черновика не перезаписывает личный кэш.

Оригинальный импорт сохранён без правок в `data/imported/`; редактируйте файлы
здесь. Кэш и полный корпус включены в общий пакет. На GitHub работа ведётся
pull request'ами в репозиторий проекта.
