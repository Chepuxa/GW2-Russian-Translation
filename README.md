# GW2 Russian Translation

Единый проект русского перевода Guild Wars 2: кириллица, Alegreya Sans Medium,
локальный переводчик, ручной каталог и общая установка. Для игрока — один ZIP
и `Install.cmd`; для участников — исходники и переводы в одном репозитории.

## Установка и разработка

Готовая локальная сборка: `dist/GW2-Russian-Translation.zip`. Распакуйте архив,
закройте игру и запустите `Install.cmd`. Python и Rust игроку не требуются.
Каталог `dist` создаётся при сборке и не хранится в Git. Для получения пакета
из исходников следуйте инструкции сборки ниже.
[Инструкция игроку](docs/INSTALL-RU.txt) · [Сборка из исходников](docs/BUILD.md).
[Как связаны компоненты](docs/ARCHITECTURE.md).
Для участия в переводе откройте `Contribute.cmd`: весь каталог черновиков,
дерево переводов, создание папок и JSON, редактор словаря терминов, перенос предложений,
просмотр разницы и PR с выбранными файлами. Локальный сбор новых строк сохранён.
[Мастерская перевода](docs/WORKSHOP.md).
Уже установленный перевод обновляется с сохранением кэша и резервной копией.
Версии компонентов и хеши записаны в `components.lock.json`.

| Где | Что находится |
| --- | --- |
| `translations/ru/` | Ручной перевод с игровыми ID, оригиналами и контекстом |
| `drafts/ru/` | Весь машинный перевод и непереведённые оригиналы для редактуры |
| `contributions/ru/` | Предложения игроков из локального сбора, всегда со статусом draft |
| `data/imported/` | Полные исходные кэш и корпус, сохранённые без правок |
| `components/local-translator/` | Русский адаптер, исходники движка, подготовка и перенос кэша |
| `components/glyphcore/` | Подключение GlyphCore и исходники считывателя архива |
| `assets/fonts/` | Alegreya Sans Medium и лицензия |
| `profiles/default.json` | Общие настройки глифов и переводчика |
| `installer/` | Установка, включение, отключение и перенос кэша |
| `tools/` | Проверка переводов, сборка и проверка общего пакета |

GlyphCore и загрузчики подключены как закреплённые внешние компоненты.
Исходники ядра GlyphCore приватные; подробнее —
[описание компонента](components/glyphcore/README.md).

## Где смотреть перевод

`translations/ru/hero/` — файлы по разделам окна героя. У каждой строки есть
`id`, английский оригинал `en`, русский текст `ru`, `context` и статус.
`reviewed` означает ручную редактуру; `draft` — предложение, которое ещё нужно
проверить. Статус сам по себе не гарантирует, что конкретная строка уже проверена
на экране: способ сопоставления и проверка указываются отдельно.

Для первой редакции английский оригинал и контекст взяты из локального сбора
игровых строк и проверки в игровом интерфейсе. Исходный английский текст,
названия и материалы Guild Wars 2 принадлежат соответствующим правообладателям.
Это независимый проект сообщества.

## Как участвовать

В игре: запустите `Contribute.cmd`, включите локальный сбор и выберите
новые строки в мастерской. Предложение можно скачать как JSON или отправить
PR после входа в GitHub. Подробности и ограничения — [WORKSHOP.md](docs/WORKSHOP.md).

Для правки файлов каталога:

1. Найти файл нужного раздела и исправить русский текст или добавить строку
   с достоверным ID, оригиналом и контекстом.
2. Запустить проверку формата, повторяющихся ID, тегов и подстановок.
3. Прислать pull request с пояснением и, по возможности, снимком из игры.
4. После редакторской проверки принятые строки попадут в пакет для игры.

Подробная инструкция — [CONTRIBUTING.md](CONTRIBUTING.md).
Согласованные термины — [glossary/ru.json](glossary/ru.json).
Проверка: `python tools/catalog.py check`.
Сборка: `python tools/catalog.py build`.
Установка только ручной редакции в настроенную игру описана в CONTRIBUTING.
Для полного пакета используется общий установщик, включающий глифы и модель.
Модель и бинарные зависимости находятся в `.artifacts/` и готовом ZIP.
В Git идут код, весь импортированный корпус и кэш, черновики, ручные переводы,
шрифт, профиль и зафиксированные хеши. Настройки учётной записи и логи
не включаются. Новый машинный перевод при подготовке этого массива не запускался.

Каталог привязывает перевод к игровому ID и хешу оригинала. При изменении
английского текста старый перевод не должен применяться к новой строке.
Пакет устанавливается в существующий reviewed-слой русского модуля,
имеющий приоритет над машинным переводом.
